# Project export settings

Three explicit content choices are supported: a private working report with selected sections, an external summary with selected current-offer fields, or a complete saved business draft (including historical versions and their warnings). Content inspection lists selected field labels, included context and excluded recorded project artifacts. No attachment bytes are bundled. References appearing in selected text are not attached files. Up to 100 excluded artifacts are displayed, with total count and truncation disclosed. This is not a computer-wide file scan or backup.

Preferences are immutable, versioned project artifacts, separate for each content choice. Saving one requires current revision/fingerprint, preview and confirmation. Reading preferences does not apply them or export anything. A selected document ID remains exact: a historical external summary becomes unavailable, while deliberate export of a complete historical document remains possible. Missing or changed fields require a fresh selection; they are never replaced with new fields automatically. Saved preferences contain no permission to send or share and no recipient, path, document contents or global default.

The local session/origin-protected API provides `export-contents` (`ref`, `selection`), `export-preferences` (`ref`), `export-preference-preview` (`ref`, `revision`, `sha256`, `selection`) and `export-preference-save` (`ref`, `preview`, `confirmed:true`). Selection matches the PDF source contract. Existing export commands remain explicitly selected and independently confirmed. In the browser, open **Export choices and preferences**. Choose a purpose and saved document when applicable, select fields, then inspect included content and excluded files. All fields start excluded. **Apply this saved selection** explicitly loads a preference for review; it never exports or approves it. **Preview saving this selection as a preference** requires a separate confirmation. Saving refreshes project revision and clears the selection, so apply it again before preparing a fresh PDF. Ordinary report export resets to its stated next-action/task defaults when reopened, instead of carrying checkbox choices across projects.

History is limited to 200 saved preference versions per project. Unreadable or inconsistent saved preference history refuses reading/updating rather than silently resetting it. Archived projects permit reading, but changing preferences requires restoration. Older versions and prior exports are preserved.
