# Review before sharing

Report, external-summary and PDF previews include a local review of the exact selected source text. Possible email addresses, phone-like numbers, HTML comment markers and common internal-note markers are listed with source line and a short excerpt. Read the complete text as well: names, postal addresses, secrets, obfuscated contacts and other sensitive content can be missed. Numbers can produce false positives. This is a review aid, not a privacy certification or permission to share.

Four manual checks remain visible even with no matches: names/private context, contact details, comments/internal notes, and draft status/scope. Existing exact-preview confirmation includes these checks. Confirmation is scoped to that preview; changes require a fresh preview through the existing revision/content gates. No permanent acknowledgment, sharing permission, redaction, network request or automatic sending is introduced. Findings are displayed as text, not HTML or executable instructions, and are not inserted into the exported document.

Only selected export text is scanned. Unselected fields, attached files, external link contents and other history are excluded. The review records a fingerprint of the complete original source and scans at most 250000 JavaScript string characters, with at most 50 findings. Either limit produces an explicit partial-inspection notice. Markdown punctuation escapes are removed only in the temporary detection view; original text, PDF bytes and prior exports are preserved. Line numbers refer to source text, not PDF page numbers.
