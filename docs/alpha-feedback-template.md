## Optional usage feedback

All answers are voluntary. Leave unknowns blank or say unknown; an unanswered question is not a failure or a zero. Do not include customer names, project paths, private records or exact activity logs.

- Approximate reporting period (optional):
- Fictional practice or own work? practice / own work / not stated
- Resumed saved work? yes / no / not tried / unknown
- Report made? yes / no / not tried / unknown
- What earlier work helped the next action, or what blocked you?

**Resumed saved work** means returning after leaving the workspace, reopening the same saved project and using earlier work for a next action. Opening a tab alone does not count.

**Report made** means confirming a report save and checking the resulting file. Previewing, an unsuccessful save or saving an ordinary offer draft does not count.

There are no automatic usage counters or background submissions. Copying a report sends nothing; you decide whether to post it. GitHub issues are public. Voluntarily submitting feedback permits review for product improvement, not identification, marketing quotations or reuse of private records.

Maintainer interpretation: record only supplied answers with their report link, package version and stated period. Keep practice separate from own work and distinguish unknown/not tried from no. Repeated updates to one report are not new people or independent sessions. Do not infer retention rates without an explicitly defined cohort and denominator. Summarize limitations with any counts. Product use does not validate a business idea. No actual usage results are recorded by this template.
