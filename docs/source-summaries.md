# Source summary provenance

Summaries record who entered them, when, the declared method (manual, AI-assisted or unknown), a tool label for declared AI assistance, limitations and an immutable source snapshot with artifact/raw fingerprints. Labels are supplied by the user, not authenticated identities or proof of authorship. Existing inbox summaries retain an unknown method; history is not relabelled.

Interpretation blocks contain contributor-supplied text. Exact excerpt blocks supply only a source range; the server derives their text from the stored raw source. Supplying invented quotation text or an out-of-range/broken-Unicode selection is rejected. An exact match is not proof of speaker identity, truth, completeness or consent. A quotation-like string inside an interpretation remains labelled interpretation. No new claims become participant statements, facts or evidence.

Both original raw text and original inbox summary remain in the comparison snapshot. Multiple summary records are immutable and do not overwrite each other. Changed/unavailable sources are flagged, and saved snapshots remain readable. Reference-only sources cannot support an excerpt or summary record. No network fetch, AI invocation, automatic business validation or source mutation occurs. Externally prepared AI-assisted text may be entered with explicit attribution.

Up to 200 records per project, 100 blocks, 8000 UTF-8 bytes per interpretation, 200000 bytes of serialized input and 1MiB per saved record. Preview/save use existing session/origin/project/revision/archive gates, distinct preview kinds, explicit confirmation and same-receipt retries. Backups include snapshots; offer exports do not automatically include them. Browser controls are implemented from a saved inbox source through Source and summary provenance: original raw text and original summary comparison, immutable attributed summary records, method/tool/alias/limitations, source excerpt selection and interpretation blocks, exact preview/confirmation, navigation guards and separate source/output columns.
