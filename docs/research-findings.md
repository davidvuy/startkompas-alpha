# Research findings

A finding is a user-created association between an existing dossier assumption and an exact stored source fragment. It is not independent evidence, validation, an answered research question or a change to the assumption's assertion.

Select either an inbox raw-text range (zero-based UTF-16 start, exclusive end, no broken surrogate pairs) or a zero-based conversation block. Reference-only inbox items have no selectable raw text. Conversation blocks preserve quotation, interpretation and follow-up separately, including missing quotations. No external text is fetched or generated.

Each immutable association stores the source artifact fingerprint, exact fragment and its identity, source context/limitations/contributor/time, the original assumption snapshot and the linking contributor/reason/time. Multiple assumptions can share the same fragment identity. The response shows the other linked assumption IDs and number of links, not independent observations or participants. The same exact fragment cannot be linked to the same assumption twice. Different ranges, source files or codes do not establish independence; duplicate source analysis is a later roadmap item.

Read-back compares current assumption/source state with the saved snapshots. Missing or changed sources are flagged, while the original saved fragment remains visible. Corrupt association history fails closed. No edits, deletion, evidence promotion, task completion or workflow updates occur. Maximum 500 associations, explicit preview/save and project revision/hash/archive/session/origin guards. Whole-project backups include the records; offer exports do not automatically include them. The browser offers Research links, source/assumption selection, a selected raw passage or full text, conversation-block selection, exact preview and confirmed save. Source selection maps textarea-normalized CR/CRLF back to original positions; splitting Unicode characters or choosing blank text is refused. Edits invalidate confirmation. Unsaved link forms are protected during project navigation but are not included in recovery copies.
