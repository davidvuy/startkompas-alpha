# Questions, bugs and security reports

Ask in Dutch or English. [Choose an issue template](https://github.com/davidvuy/startkompas-alpha/issues/new/choose) for questions, bugs, feature suggestions or first-use feedback. A GitHub account is required. Follow the issue for replies.

Issues are public. Share only a small fictional example, your package version, operating system, Node version and the steps you tried. Do not upload private dossiers, customer data, credentials or complete conversations.

For sensitive vulnerabilities, use [private vulnerability reporting](https://github.com/davidvuy/startkompas-alpha/security/advisories/new). If that route is unavailable, do not publish sensitive details in an issue.

There is currently no support mailbox, live chat, automatic issue responder or guaranteed response time. GitHub notifications depend on your account settings. Never assume a report has been seen until someone replies.

## Common questions

**Does the demo need an API key?** No. The deterministic local demo makes no AI calls. AI-assisted use through Codex depends on that provider's access, charges and data handling.

**Where should my project go?** In a separate private directory outside the application. Keep backups.

**Can I reuse the demo destination?** Choose a new directory each time. The demo deliberately refuses to overwrite an existing directory.

**Does a passing test prove business demand?** No. Technical checks verify software behavior with synthetic data, not customer demand or professional advice.

**Will updates change my existing project automatically?** No. Install a new application copy separately and test with a project copy or export first.

**How can I help?** Report whether you could install, get a useful first result and resume later. Explain the task that mattered to you. Do not share real customer data.
